# SPPK Jawa Timur

Aplikasi pendukung keputusan prioritas mitigasi banjir dan longsor di 38 kabupaten/kota Jawa Timur, memakai AHP + TOPSIS.

## Jalan di komputer sendiri

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000).

## GitHub Pages

Situs: [https://aziizpranaja.github.io/sppk-jawa-timur/](https://aziizpranaja.github.io/sppk-jawa-timur/)

Setiap push ke `main` membangun versi statis dan men-deploy otomatis.
